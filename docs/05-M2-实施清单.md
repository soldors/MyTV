## 2. 实现中的关键决定

1. **播放走站内代理**（非直连）：采集站 m3u8 普遍无 CORS 头且部分有 Referer 防盗链，代理重写分片为同源路径后 hls.js 稳定可用（LibreTV 同策略）。
2. **share 播放器页解析**（`api/proxy/[url]/route.ts` 新增）：量子源 vod_play_url 实测为 `/share/<id>` 网页（真实 m3u8 在 `var main = "..."` 脚本变量里），代理遇 text/html 响应时提取 m3u8 代取（过 SSRF 校验），对播放器透明；**HTML 透传改 `no-store`**（曾被 `max-age=3600` 投毒缓存）。
3. 首页推荐位（豆瓣榜）按计划留二期，M2 首页内容=云端数据（继续观看/收藏），无记录时品牌 Hero + 热搜词引导。
4. 登录页背景用 CSS 渐变拼贴替代外部海报拼贴（避免外部资源依赖，视觉基调一致）。
5. 进度保存策略：`video:timeupdate` 10s 节流 + `pause` 兜底 + 切集显式保存；**不做 destroy 保存**（切集重挂载时旧实例闭包持旧集号且 currentTime 已重置，实测会产生覆盖竞态）。
