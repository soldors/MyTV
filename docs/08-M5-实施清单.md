# MyTV M5 实施清单 v1

> 状态：已完成（2026-09-29），解析器单元验证 + 浏览器真实播放实测 + 线上部署通过。
> 依据：`01-总体设计方案.md` #7（直播/IPTV 保留，M5 移植）、§9.1（直播源随直播里程碑）。
> 目标：移植上游直播模块（M3U + XMLTV EPG），前台 /live 页走通「选源 → 选台 → 播放」。

## 1. 交付内容

| 模块 | 文件 | 说明 |
|---|---|---|
| M3U 解析 | `src/lib/m3u-parser.ts` | 上游移植：标准/非标准 EXTINF、#EXTGRP、相对地址解析、URL 去重、rtp/udp 等不可播协议过滤、URL 派生稳定 id |
| XMLTV 解析 | `src/lib/xmltv.ts` | 上游移植：单趟正则扫描（不做 DOM）、gzip 魔数识别解压（node:zlib）、24h 时间窗裁剪、实体安全解码、currentAndNext；**适配：typeof 守卫替代 Buffer.isBuffer**（@types/node 26 下 else 分支不再收窄） |
| 直播缓存 | `src/lib/live-cache.ts` | 上游移植：独立于通用缓存的大对象 TTL 池（EPG 可达数十 MB，避免连带清掉热点数据）；**适配：总容量 256MB → 64MB**（Workers isolate 128MB 上限） |
| 频道过滤 | `src/lib/live-channel-filter.ts` | 上游移植（纯函数）：搜索归一化（cctv1 命中 CCTV-1）、分组过滤、排序模式（探测排序留待频道测活） |
| env 直播源 | `src/lib/env-live-sources.ts` | `DEFAULT_LIVE_SOURCES`：[{name, url(M3U), epg?(XMLTV 支持 .gz)}] |
| API | `api/live/playlist` `api/live/epg` | 上游移植：playlist 拉 M3U 解析（10min 缓存、force、format=m3u 导出）；epg 拉 XMLTV（6h 缓存、按频道查询）。均走 `checkLiveUrlAllowed`（`LIVE_ALLOW_PRIVATE=1` 放行自建内网 IPTV）+ allowPrivate 逐跳校验 |
| 源出口 | `api/sources` | 响应增加 `liveSources`（env 预置；后台管理直播源随后续迭代） |
| 前台 | `(site)/live/page.tsx` | 源 pills（含 EPG 标记）→ 分组 pills + 频道搜索（归一化）→ 频道列表（台标/分组/渲染上限 300）→ 播放器（同源代理）→ EPG 当前/下一档节目（进度条）；自定义 m3u8 直播流直接粘贴播放；最近观看 localStorage 恢复 |
| 导航 | `site-nav` | 桌面顶栏与手机底栏均增「直播」（底栏 3→4 Tab），新 IconTv |
