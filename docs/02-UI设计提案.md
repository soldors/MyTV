## 4. 对比与推荐

| 维度 | A 暗夜影院 | B 雾光玻璃 |
|---|---|---|
| 观感 | 沉浸、影院感、内容绝对主角 | 清新、杂志感、呼吸感 |
| 观影场景（夜间/弱光） | 优 | 一般；选 B 须一期加暗色模式 |
| 海报表现力 | 深色衬海报色彩，边缘融合 | 白底干净，但深色海报边缘对比突兀 |
| 差异化 | 与 Netflix 系同构，成熟稳妥 | 同类聚合站少见，辨识度高 |
| 实现成本 | 低（单暗色主题） | 中高（玻璃模糊需性能调优；暗色模式另算） |
| 主要风险 | 同质化 | 夜间体验差、主题翻倍维护成本 |

**推荐 A**。产品核心场景是"看片"，暗色为业界验证过的正解，且与 9.2 既定「默认暗色」一致、成本最低；B 的差异化代价是双主题维护。

## 7. 交互与实现规格

### 7.1 信息架构
- **详情页与播放页合一**：播放页即详情落地页（含简介/收藏/选集），海报与搜索结果点击直达，减少一跳。
- 前台路由：`/`（首页）、`/search`、`/play/:source/:id(/:ep)`、`/my`、`/login`；后台路由：`/admin/*`（9.1 分离）。
- 导航：电脑顶部导航；手机底部标签栏（首页/搜索/我的）；平板顶部紧凑导航；后台独立侧边栏工作台，仅管理员从「我的 → 管理后台」进入。

### 7.2 关键交互
- Hero 轮播 5s 自动切换 + 指示点；海报 hover（desktop）放大 1.05 + 红光晕；点击直进播放页。
- 播放器：控制条 3s 无操作自动隐藏；选集网格当前集红色填充；「跳过片头」按钮按 skip_configs 出现。
- 搜索：输入即显历史/热搜，Enter 出结果；历史未登录存本地，登录后同步 D1。
- 加载：海报骨架屏；图片懒加载 + 渐变占位；失败重试占位。
- 后台表格：启用开关即时生效（乐观更新 + 失败回滚 toast）；删除二次确认。

### 7.3 主题令牌落地
CSS variables：`--bg #0B0E14`、`--elevated #131822`、`--overlay #1B2230`、`--accent #E8112D`、`--rating #F5C518`、`--text-1/2/3`；Tailwind 配置同名映射；一期仅暗色主题，令牌结构预留亮色。

### 7.4 组件清单（shadcn/ui 映射，待 #12 拍定）
基础：Button / Input / Tabs / Dialog / Toast / Skeleton / Switch / Table / DropdownMenu / Tooltip。
业务：PosterCard、HeroCarousel、EpisodeGrid、SourceTabs、PlayerBar（ArtPlayer 定制皮肤）、SearchPanel、AdminSidebar、StatCard、SourceTable。

### 7.5 后台设计基调
与前台同暗色令牌；信息密度更高、装饰收敛；圆角收窄（8px）；红色仅用于主操作与告警。
