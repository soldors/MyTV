## 2. 工程初始化

1. `git init`（当前目录非 git 仓库）；`LICENSE` 放 AGPL-3.0（#2）；README 挂「源码公开」说明。
2. Next.js 15 + TypeScript + Tailwind + App Router（`src/` 目录），`images.unoptimized`（上游同策略，采集站地址运行时不可枚举）。
3. 接入 OpenNext：`@opennextjs/cloudflare` + `open-next.config.ts` + `wrangler.toml`（`compatibility_flags = ["nodejs_compat"]`，compatibility_date 取部署时最新；D1/KV 绑定先注释预留，M1/M3 启用）。
4. shadcn/ui init（#12）；route group 骨架：`app/(site)/` 与 `app/(admin)/admin/`（#14）。
5. 脚本约定：`dev`（next dev）、`preview`（opennext 构建 + wrangler dev）、`deploy`（opennext 构建 + wrangler deploy）、`typecheck`、`test`。
6. 目录骨架：

```
src/
├─ app/
│   ├─ (site)/page.tsx          # M0 占位首页（显示源探活状态，证明端到端）
│   ├─ (admin)/admin/page.tsx   # M0 占位（中间件护栏验证用）
│   └─ api/                     # 全部移植自上游（见第 3 节）
├─ lib/                         # 移植 + 自研
├─ middleware.ts                # 自研（上游无此文件）
└─ components/                  # M0 仅占位；M2 按设计稿实现
```

## 3. 服务端移植清单（上游 LibreSpark/LibreTV @ v2.15.0）

| 模块 | 移植文件（上游路径） | 改动点 |
|---|---|---|
| 代理层 | `src/app/api/proxy/[url]/route.ts`、`src/lib/ssrf.ts`、`src/lib/fetch-utils.ts` | ssrf 的 DNS 校验由 node:dns 改为 **DoH（cloudflare-dns.com → alidns 回退，2.5s 超时，结果缓存）**——Workers 无 node:dns；其余照搬 |
| 苹果CMS 采集 | `src/app/api/search/route.ts`、`src/app/api/detail/route.ts`、`src/app/api/source/test/route.ts`、`src/lib/cms-parser.ts` | 照搬 |
| TVBox 订阅 | `src/lib/tvbox-parser.ts`、`src/lib/source-list.ts`、`src/app/api/source-list/route.ts`、`src/lib/env-sources.ts`、`src/lib/env-subscriptions.ts` | env 变量名沿用上游 `DEFAULT_SOURCES` / `DEFAULT_SUBSCRIPTIONS`；品牌串改 MyTV |
| 会话鉴权 | `src/lib/auth.ts`、`src/lib/api-guard.ts`、`src/app/api/auth/route.ts` | auth 去 setInterval（Workers 无，改惰性清理）；cookie 名 `mytv_session`、派生盐改 MyTV；middleware 侧另有 WebCrypto 复刻校验（见下） |
| **自研新增** | `src/middleware.ts`：`/admin/*`、`/api/admin/*` 管理员会话强制，非授权 404 | 上游无中间件；middleware 无 node:crypto，用 WebCrypto 复刻 HMAC 校验（与 lib/auth.ts 互通，已实测） |

**不移植**（UI/客户端，全部自研于 M2）：`src/components/*`、各页面、`src/lib/db.ts`（dexie）、`store.ts`、`persist-storage.ts`、`video-cache.ts`、`video-prefetcher.ts`、`hls-loader.ts`、`m3u8-downloader.ts`、`playback-recovery.ts`、`subscription-sync.ts`（客户端订阅同步，依赖 zustand store）、`smart-image` 等。

**二期移植**：直播 `src/app/api/live/*` + `src/lib/m3u-parser.ts`、`xmltv.ts`、`live-cache.ts`、`live-channel-filter.ts`、`env-live-sources.ts`（M5，#7）；推荐 `douban/bangumi/hot-list` 相关（随首页推荐位，二期）。
