## 2. 关键决定

1. **DB 源 key 独立生成**（`db_` + 8 位随机 hex）：不与 env 源的 `env_N` 冲突，作 `/play/:source` 路径段稳定可存（播放记录/收藏引用它）。
2. **订阅导入不回滚**：删除订阅只删记录，已导入的源在数据源页单独管理（导入是「批量建源」动作，非持续同步语义；重新同步=再次导入增量）。
3. env 预置源在后台只读展示（改它需改环境变量重部署）；管理动作全部面向 DB 源。
4. 站点配置沿用 M1 的 `admin_configs` 单行 JSON（json_patch 原子合并），前端类型 `SiteConfig` 增加 `siteName/announcement`（展示位随 M2 前台迭代接）。
