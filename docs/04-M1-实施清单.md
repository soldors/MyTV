| 验证页 | `src/app/(site)/page.tsx` | 占位首页加「多用户与云端记录」区（注册/用户登录/写读记录/登出） |

## 2. 对设计稿（§5 DDL 草案）的细化决定

1. `users` 增加 `status`（pending/active/disabled，承载 #9 注册审批与禁用）与 `iterations`（PBKDF2 参数随行，便于日后提升强度）。
2. `play_records.index` 列改名 `episode_index`（`INDEX` 为 SQLite 保留字）。
3. 站长不落库：环境变量 `PASSWORD` 登录后会话身份为 `admin`（role=admin），其云端数据以 `user_name='admin'` 落 D1；注册名 `admin` 被保留。
4. **会话格式升级导致旧 cookie 失效**：v1 token（无身份段）一律判无效，部署后需重新登录（PASSWORD 轮换同理，非新增风险）。

## 3. 资源与绑定

- D1：`mytv-db`（id `c779fce0-b6ee-4827-a58d-d02416126f4e`，区域 WNAM），绑定名 `DB`，`wrangler.toml` 已启用，`migrations_dir = "migrations"`。
- 远程迁移与部署：`wrangler d1 migrations apply mytv-db --remote` → `pnpm deploy`，线上版本 `2988510a-cf8a-49b9-b507-e719dcb89bc8`。
- 审批操作（M4 界面就绪前的临时手段）：`pnpm exec wrangler d1 execute mytv-db --remote --command "UPDATE users SET status='active' WHERE name='...'"`。
